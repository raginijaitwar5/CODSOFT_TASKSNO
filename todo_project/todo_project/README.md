# To-Do List Application

Two versions of the same app:

1. todo_app.py   - Command-line app (Python 3.7+, no extra packages)
   Run:  python todo_app.py
   Tasks are saved to todo_data.json in the folder you run it from.

2. todo_app.html - Web version. Double-click to open in any browser.
   Tasks are saved in the browser (localStorage).

Features: add, view, update, complete/reopen, delete, search,
priorities (High/Medium/Low), due dates, overdue flags, progress summary.
